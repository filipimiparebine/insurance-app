# TEC-161.1: Unify i18n — Remove Custom i18n, Use next-intl Everywhere

**Assignee:** Frontend Lead
**Priority:** P0 (blocks production)
**Estimate:** 2 days
**Dependencies:** None

## Problem

Two i18n systems run simultaneously:
1. Custom `t()`/`setLocale()` in `packages/shared/src/i18n/index.ts` — global mutable state, defaults to `'ro'`
2. `next-intl` in `apps/web/` — proper middleware routing, locale detection

UI components in `packages/ui/` import `t` from `@blaj/shared` directly and **never call `setLocale()`**. Result: shared components always render in Romanian.

## Scope

### Impact Analysis
- `packages/ui/src/components/*.tsx` — 10+ wizard components importing `t` from `@blaj/shared`
- `packages/ui/src/index.ts` — exports
- `packages/shared/src/i18n/index.ts` — the custom i18n implementation
- `apps/web/src/i18n/request.ts` — bridges custom i18n to next-intl
- `packages/shared/src/i18n/translations/ro.ts` — RO translation keys
- `packages/shared/src/i18n/translations/en.ts` — EN translation keys
- `apps/web/src/app/[locale]/layout.tsx` — locale initialization

## Requirements

1. **Remove custom i18n** from `@blaj/shared` — delete or archive `packages/shared/src/i18n/index.ts`
2. **Refactor UI components** to accept translation function via props or React context instead of direct import
3. **Keep translation files** in `@blaj/shared` (or move to `@blaj/ui`) — they're the source of truth for keys
4. **Wire next-intl** to pass correct `t()` to all UI components via provider or HOC
5. **Verify all locale routes** — `/ro/*` and `/en/*` must render correctly
6. **Preserve** `formatPrice`, `formatDate`, `pluralize` utilities — move to `@blaj/shared/i18n-utils.ts`

## Acceptance Criteria

- [ ] No imports of `t` from `@blaj/shared` in any component — only from next-intl or via context
- [ ] `/en/*` routes render labels in English (not Romanian)
- [ ] `/ro/*` routes render labels in Romanian
- [ ] Locale switch (if implemented) updates all visible strings
- [ ] `formatPrice`/`formatDate`/`pluralize` still work in both locales
- [ ] No regression in wizard functionality
- [ ] All translation keys in `ro.ts` and `en.ts` are preserved

## Files to Modify
- `packages/shared/src/i18n/index.ts` — archive or delete
- `packages/ui/src/components/*.tsx` — 10+ components, change `t` import to prop/context
- `packages/ui/src/export.ts` — remove re-exports of i18n if any
- `apps/web/src/i18n/request.ts` — simplify or remove bridging
- `apps/web/src/app/[locale]/layout.tsx` — add translation provider wrapping UI components
- `packages/shared/src/index.ts` — update exports
