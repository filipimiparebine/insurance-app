## Part A: Fix Type Safety (`any` types + `Record` casts)

### Files
- `packages/ui/src/components/owner-step.tsx:23-26,215-216,259-260`
- `packages/ui/src/components/config-step.tsx:113`

### Requirements
1. **OwnerStep** — Replace `// eslint-disable-next-line @typescript-eslint/no-explicit-any` on `register` and `errors` props with proper generics:
   - `register: UseFormRegister<OwnerFormValues>`
   - `errors: FieldErrors<OwnerFormValues>`

## Part C: Implement Role-Based Routing

### Files
- `apps/web/src/middleware.ts`
- `apps/web/src/app/[locale]/dashboard/page.tsx`

### Requirements (per TEC-79 spec)
1. Read role from Clerk `sessionClaims.metadata.role`
2. Implement middleware-level guard:
   - `admin` role → redirect to admin dashboard
   - `agent` role → redirect to agent dashboard  
   - `user` role → regular customer dashboard
