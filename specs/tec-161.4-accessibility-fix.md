## CTO Note (2026-05-18)

**Stepper fix implemented in this heartbeat.** Changes in `packages/ui/src/components/stepper.tsx`:
- Added `role="tab"` on each step indicator with `aria-selected` and `aria-current="step"`
- Added `role="progressbar"` with `aria-valuenow`/`aria-valuemin`/`aria-valuemax` on progress bar
- Added `tabIndex` (0 on active step, -1 elsewhere) and `focus-visible:ring-2` for keyboard navigation
- Added `aria-label` with status context on each step
- Added `aria-hidden="true"` on decorative icons

**Remaining for Frontend Lead:** Apply the same pattern to `drop-zone.tsx` — add `role="button"`, `tabIndex={0}`, keyboard handler for Enter/Space, and `aria-label`.

## Problem

### Stepper (`stepper.tsx:33-61`)
- Step indicators are plain `<div>` + `<span>` — not keyboard-focusable
- No `role="tablist"` / `role="tab"` / `role="tabpanel"` attributes
- No `aria-current="step"` on the active step
- Keyboard users cannot navigate steps
- Screen readers get no semantic structure

### DropZone (`drop-zone.tsx:112-159`)
- Hidden `<input>` for file selection
- `onClick` on parent div but no `onKeyDown` handler for Enter/Space
- Screen reader users cannot activate file selection
- No `role="button"`, no `tabIndex={0}`

## Requirements

### Stepper
1. Convert step indicators to `<button>` elements
2. Add `role="tablist"` to the container
3. Add `role="tab"` to each step button
4. Add `role="tabpanel"` to step content
5. Add `aria-current="step"` on the active step button
6. Add `aria-selected={isActive}` on each tab
7. Ensure keyboard navigation (arrow keys between steps if applicable)

### DropZone
1. Add `role="button"` and `tabIndex={0}` to the drop zone
2. Add `onKeyDown` handler for Enter (key code 13) and Space (key code 32)
3. Ensure the hidden `<input>` is accessible (associate with `aria-label`)
4. Add `aria-label` describing the action (e.g., "Încarcă talon și CI" / "Upload registration and ID")
5. Announce drag state changes via `aria-live` region

## Acceptance Criteria

- [ ] Stepper steps are keyboard-focusable via Tab
- [ ] DropZone is keyboard-activatable via Enter/Space
- [ ] Screen reader announces step structure and current step
- [ ] Screen reader announces DropZone purpose and file selection
- [ ] No regression in mouse/touch behavior
- [ ] Passes basic axe-core audit for both components
